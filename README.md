# Credit-Default-Risk-Model-FICO-Score-Segmentation
## Business Question
Can borrower financial characteristics and FICO scores be used to estimate probability of default and create meaningful credit risk segments?

## Methods
- Cleaned and prepared borrower loan data
- Engineered debt-to-income and payment-to-income ratios
- Built a logistic regression model to predict loan default
- Evaluated classification performance using error rate and ROC-AUC
- Segmented FICO scores into risk buckets using default rates and maximum likelihood estimation

## Tools
Python, Pandas, NumPy, Scikit-learn, Matplotlib

## Business Use Case
Credit risk teams can use this type of model to estimate borrower default probability, assign risk grades, and support lending or portfolio risk decisions.
